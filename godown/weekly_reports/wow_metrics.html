How to read this report
Week columns are Monday-start weeks; the last column is the current, partial week (Mon → today).
Counting rule for all funnel stages: a deal is counted in the week it entered that stage. Only human actions count — HubSpot's sourceType = CRM_UI; bulk API / migration / script writes (~42% of all stage changes) are excluded, so these are things a person actually did.
  • Calls attempted — a deal entered a dialled stage (No Pickup / Interested / Not-Interested / Wrong-Number). A dial happened.
  • Calls connected — entered Interested or Not-Interested, i.e. someone picked up and talked.
  • VCs done — entered a video-call / meeting-held stage (Script Shared or a Dead-after-GMeet outcome).
  • Scripts shared — entered Script Shared.  Script output received — entered Script Results Received.
  • Commercial negotiation — entered Commercial Negotiation.  Deal Contract signed — entered Deal Contract Signed.  Closed/Won — entered Closed/Won.
  • LoC closed (Mn) — sum of the deal's loc (lines of code) for deals that reached Closed/Won that week, in millions.
  • LoC in pipeline (Mn) — sum of loc for deals still open (not won, not dead) as of that week's end — a running size of the open pipeline.
  • Net New Leads Engaged (genuine) — leads that got their first human touch that week, after removing wrong-number and wrong-SPOC rejects.
  • ↳ wrong-number / SPOC removed (ref) — how many first-touched leads were stripped: wrong-number = hit the Wrong-Number stage or a "bad number" note; wrong-SPOC = a note saying wrong person / wrong POC / not a founder. Shown only for reference — the dialling effort still counts under Calls Attempted.
Genuine engaged — by lead source: the same genuine-engaged leads, broken out by which channel they came from.
Genuine engaged — by furthest pipeline stage: the same leads, each counted once, at the deepest stage it ever reached. "Touched, screened before dial" = engaged but screened out (wrong-fit) before an actual dial. This split sums to Net New Leads Engaged (genuine).
